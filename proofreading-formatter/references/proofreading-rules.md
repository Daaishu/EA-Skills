# Proofreading Rules

文字校对的五类检查项及常见错误类型。校对时按此清单逐项扫描，记录所有修改，在交付时告知用户。

## 1. 错别字

### 同音字混淆

| 错 | 对 | 说明 |
|----|----|------|
| 不愧于 | 无愧于 | |
| 启用 / 起用 | 各有其义 | 启用指启动使用（设备、程序）；起用指重新任用（人） |
| 截至 / 截止 | 截至 + 时间 | "截至 2026 年 3 月"，"申报截止"（不接时间） |
| 即 / 既 | 即是就是；既是已经 | |
| 的 / 得 / 地 | 名词前"的"，动词后"得"，动词/形容词前"地" | |
| 做 / 作 | 做事/作报告 | 具体动作用"做"，抽象用"作" |
| 按 / 安 | 按照/安装 | |

### 形近字混淆

- 部 / 步、己 / 已 / 巳、未 / 末、壁 / 璧、辩 / 辨 / 瓣

### 人名、地名、机构名前后不一致

校对时特别注意同一实体在文中不同位置是否写法一致。例如第一次出现写"中国科学院大学"，后文不能简写为"国科大"除非首次出现时已注明简称。

## 2. 病句与语法

- **成分残缺**：缺主语、缺谓语、缺宾语
- **搭配不当**："提高水平"对，"提高质量"对，但"提高损失"错
- **语序错误**：定语/状语位置不当
- **重复冗余**：如"莅临光临"、"大约 100 余人"、"凯旋归来"、"目的是为了"
- **关联词错用**："虽然……却……" 正确；"虽然……但是……" 正确；"不但……反而……" 错

**常见冗余示例：**

| 错 | 对 |
|----|----|
| 大约 100 余人 | 约 100 人 / 100 余人 |
| 目的是为了提升 | 目的是提升 / 为了提升 |
| 凯旋归来 | 凯旋 |
| 免费赠送 | 赠送 / 免费提供 |
| 首当其冲地成为第一个 | 首当其冲 / 成为第一个 |

## 3. 标点使用

### 中英文标点使用场合

- **中文语境**：用全角标点（，。；：？！""''（）《》）
- **英文或数字间**：用半角标点（, . ; : ? !）
- **混排**："某某项目（Phase I）于 2026 年启动" — 括号随外层语言

### 常见错误

- 省略号应为"……"（六个点两组），不是"..."
- 破折号应为"——"（两个全角短横），不是"--"
- 书名号用《》，不用 < >
- 并列成分之间用顿号"、"，不用逗号：正确"北京、上海、深圳"，错误"北京，上海，深圳"
- 冒号后引文用双引号，冒号不连用
- 引号使用全角""和''，避免直引号 " '

### 半角括号残留

从网页或英文源复制的文本常残留半角括号 ()，在中文语境应替换为全角（）。

## 4. 数字用法

遵循《出版物上数字用法》GB/T 15835。

### 使用汉字的场合

- 整数一至十（如"一是、二是、三是"）
- 成语或固定表达（"三令五申"、"四海为家"）
- 序数词与"第"搭配一般用阿拉伯数字，但"第一"、"第二"在描述层级时用汉字
- 概数（"五六十人"、"三四天"）
- 年份不能拆写："一九四九年"或"1949 年"，不能写"49 年"

### 使用阿拉伯数字的场合

- 精确统计数据（"利润 2.4 亿元"）
- 日期时间（"2026 年 4 月 5 日"）
- 百分比（"增长 15%"）
- 货币金额
- 编号序号（"第 3 条"、"表 2"）

### 公文中的特殊规范

公文的层级标号用汉字：一、二、三…… 和 （一）（二）（三）……
具体条文下的编号用阿拉伯数字：1．2．3……

## 5. 专有名词一致性

通读全文，标记所有专有名词，确认：

- **人名**：全文姓名、职务、头衔写法一致
- **机构名**：首次出现用全称，后续可用简称，但全文简称统一
- **项目名、产品名**：大小写、空格、特殊字符一致
- **地名**：行政区划完整性一致（"上海"还是"上海市"）
- **时间表述**："2026 年 4 月 2 日"还是"2026 年 4 月 2 日周四"统一

## 校对报告格式

向用户汇报修改时，使用如下结构：

```
校对发现的修改：

1. 错别字
   - 第 X 段"截止 2025 年"→"截至 2025 年"
   - 第 Y 段"启用新规"→"施行新规"

2. 标点规范
   - 第 Z 段省略号"..."改为"……"
   - 全文半角括号()统一为全角（）

3. 数字用法
   - 第 X 段"49 年"补全为"1949 年"

4. 其他
   - ……
```

如果原文质量很高、未发现明显问题，也如实说明：

> 原文质量较高，未发现明显错别字或语法错误，仅对标点做了轻微调整。
