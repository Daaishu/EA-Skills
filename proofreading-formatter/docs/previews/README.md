# Format Previews

This directory is where the three format preview screenshots live.

Expected files (filled in when the screenshots are added):

- `format-a-policy-report.png` — Format A (government formal report) page 1
- `format-b-project-brief.png` — Format B (internal briefing) page 1
- `format-c-forum-agenda.png` — Format C (event agenda) cover page
- `format-c-forum-agenda-page2.png` — Format C attendee list page

These previews should be generated by opening the corresponding `examples/*/output.docx` file in Microsoft Word on Windows and taking a screenshot — not by rasterizing from LibreOffice or other open-source renderers, which will substitute different fonts and produce visually different results from what end users see.

To regenerate the example `.docx` files:

```bash
node scripts/build_docx.js examples/format-a-policy-report/content.json examples/format-a-policy-report/output.docx a
node scripts/build_docx.js examples/format-b-project-brief/content.json examples/format-b-project-brief/output.docx b
node scripts/build_docx.js examples/format-c-forum-agenda/content.json examples/format-c-forum-agenda/output.docx c
```
